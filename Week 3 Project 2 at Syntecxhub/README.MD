# HR Analytics Dashboard

## Project Overview 
This repository contains an interactive **HR Analytics Dashboard** designed to help organizations discover hidden insights within their workforce data. 
## Objectives of the Project
The primary objective is to track key performance indicators (KPIs), analyze employee attrition patterns, evaluate departmental performance, and provide data-driven recommendations to improve employee retention and satisfaction. The Project delivers a comprehensive look at demographics, compensation, tenure, and satisfaction levels to understand why employees are leaving and where interventions are most urgently needed.
