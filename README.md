# E-Commerce Sales Performance Dashboard

This Power BI dashboard provides a comprehensive analysis of e-commerce sales performance, enabling stakeholders to monitor key business metrics and identify growth opportunities. The dashboard tracks Revenue, Sales, Profit, Quantity Sold, and Yearly Growth Rate, while offering interactive filters for Region, Year, and Product Category.

Key visualizations include sales and profit trends by month and quarter, category-wise sales performance, top-selling products, and yearly profit distribution. The dashboard helps uncover customer purchasing patterns, evaluate product performance, and support data-driven business decisions through clear and actionable insights.

Tools Used: Power BI, Data Modeling, DAX, Data Visualization
Key Features: KPI Cards, Interactive Slicers, Trend Analysis, Product Performance Analysis, Profitability Insights, and Growth Tracking.
